# 自愿支持入口

本轮按用户确认的方案，在“我的”页面的“隐私与帮助”之后、版本信息之前放置“支持 Bes记账”，打开“让记账更顺手”卡片。说明保留“开源（查看 GitHub 源代码 ↗）”、免费、无广告与自愿支持；金额由使用者决定，使用、分享和反馈同样是支持。

手机采用底部卡片，桌面和平板横屏并排展示说明与二维码。保存按钮放在二维码之前，关闭按钮不随内容滚走；支持 Esc、系统返回和关闭后的焦点恢复。钱包的短动效只反馈打开，减少动态效果时取消动画。二维码不改变账本、不建立订单、不检测付款，也不自动新增支出。

## 图片来源与体积

用户明确同意在 Bes记账使用微信、支付宝两种收款码，并要求兼顾清晰度与 APK 体积。以下图片沿用其 BesFuel、BesMapLab 等项目中一致的收款素材，仅进行无损格式转换，不裁剪、缩放、重绘或改变收款主体。

| 方式 | 原 PNG 尺寸 | 原文件字节 | 无损 WebP 字节 | 可见收款人 |
| --- | --- | ---: | ---: | --- |
| 微信 | 1266 × 1749 | 165920 | 65952 | Benson(**城) |
| 支付宝 | 1080 × 1680 | 484562 | 283128 | Bes软件 |

原 PNG 来源为 BesFuel 的 `resources/support/`，SHA-256 分别为 `a89ad9f33ecc5b9bc6a6bf5587fa16cd04809d3bfbcaac58a0731faceae41449` 和 `5f5722d5a30ecbd5d51684a2051eb40961070c8954a2f3b3eef403f526f367d4`。打包使用 `src/assets/support/` 的 WebP，两张合计由 650482 降至 349080 字节，减少约 46%；解码后的 RGBA 像素逐一相同。原 PNG 不重复放进 APK。

保存时在设备上按原尺寸输出 PNG。Web 下载到本机；Android 通过现有系统分享面板选择保存或接收图片的应用，打开面板不代表已保存或付款。PWA 缓存包含两张码，完成首次缓存后可离线查看与保存。付款前仍需在支付应用中核对实际收款人；微信、支付宝相册识别需用户真机确认。

收款图片归作者所有，不因仓库代码采用 MIT 许可而授予第三方将其用于自己的收款页面的权利。

## 标识一致性

`src/assets/brand.svg` 为钱包标识的唯一矢量源。创建/解锁页、侧栏、“我的”和支持卡片都使用构建产生的内容摘要路径，网页标签和 Apple Touch 图标亦使用摘要路径，避免固定 `icon.svg` URL 的旧 B 图标缓存。`generate-icons.mjs` 与 `generate-android-icons.mjs` 从同一源生成 README 兼容副本、PWA 与 Android 资源；更新图标后应运行这两个脚本。

用户在本地交互预览确认后，授权纳入统一 0.1.3 发布。更新说明与 README 以界面改进和新图标为主，不突出支持入口，也不为此单独创建 Release。
