# 内置分类与常用项排序

日期：2026-10-21。用户已确认采用通用内置分类、用过后加入常用候选，以及周权重最高的频率排序方向。以下具体默认项、权重、展示数量和稳定性阈值是当前建议，可继续调整。当前实现仅为会话内 UI 演示。

## 分类范围

以用户提供的完整分类截图为参考，保留餐饮、交通、购物、娱乐、医教、居家、投资、人情、生意九个支出大类；收入采用一级分类。低频的育儿、养老、商务等通用类别放在完整列表中，不挤占初始快捷项。

完整名称、图标、预置 ID 和默认快捷项见 [内置分类清单](examples/builtin-categories.json)。ID 是稳定身份，后续改名、调序或新增时不得按当前位置重编。私有账目、原图和金额未写入清单。

取舍规则：

- “直播礼物”“健身饮食”等个人细分项由用户自建；收入中的“软件捐款”归纳为更通用的“捐赠收入”，不预设个人产品专用名称。
- 日用百货统一为家居百货，衣服鞋包统一为服饰鞋包；保留用户熟悉的餐饮、交通等大类。具体旧分类映射由导入流程确认，不自动改写用户历史数据。
- 保险与保险费合并为居家的保险费，车险保留在交通；定期利息可使用利息，也可自行细分。电视类支出采用更通用的影音会员。
- 车款车贷、房款房贷分别保留购车支出、购房支出作为购买支出选项；偿还贷款本金使用转账／借贷，实际利息使用利息支出。
- 退款返款使用关联退款；应收款和可收回的代付款使用借贷往来；助学贷款、消费贷款、投资贷款本金使用借贷或转账；漏记款先核对历史或账户调整，不默认作为普通收支。
- 基金、股票、余额宝、银行存款等资金划转使用转账类型和资金账户。实际收益使用投资收益、利息或分红，费用使用投资手续费；不把赎回总额当收入。P2P 等特定投资渠道不内置为普通支出类别。
- 报销款保留为可选收入名称；是否与原支出关联及其统计口径需要专门设计，不能据此自动推断为新收入或退款。公积金收入也只记录实际新增缴存，账户间提取属于转账。

## 初始快捷项

手机按四列排列。最后一格固定为圆形省略号与“全部”文字，永远不参与排序，也不是可保存的分类。收入和支出各自进入对应的完整分类；完整列表支持搜索和自定义类别。

| 类型 | 初始顺序 | 布局 |
| --- | --- | --- |
| 支出 | 早餐、午餐、晚餐、买菜原料、饮料水果、家居百货、打车、加油、停车费、水电燃气、手机电话 | 11 个类别＋全部，共三行 |
| 收入 | 工资薪水、奖金、兼职外快、红包、福利补贴、利息、报销款 | 7 个类别＋全部，共两行 |

使用过的类别进入该账本、该收支类型的常用候选池，与初始快捷项一起排序。屏幕只显示前 11／7 项，其余始终可从“全部”选择；候选项增加不使记账页无限增长。未使用的内置类别不参与竞争。自定义类别按相同规则处理。

## 使用次数口径

- 手工新建账目、粘贴识别并确认保存后，按最终分类计一次；仅点击、取消、校验失败或只创建分类不计次数。
- 按实际确认分类并保存的操作时间统计，不按账单发生时间统计，适合集中补记旧账。滚动窗口为最近 7／30／365 天，不按自然周或自然月重置。
- 自动周期生成、历史批量导入、同步拉取／重放不增加快捷项使用次数；用户手工确认一笔短信仍计一次。
- 正式实现按稳定交易 ID 保留最近一次有效手工分类使用记录。同一笔只改金额或备注不加次数；改分类后替换原分类贡献，删除／撤销账单后移除，重试不得重复计数。
- 收入、支出独立统计；暂按当前账本统计，避免旅行账本习惯挤占日常账本。分类是否共用仍是独立的待确认决策。
- 转账五种行为和借贷四种操作维持固定顺序，不参加收支常用分类排序。

## 排序建议

不能直接把周、月、年的原始笔数按 60／30／10 相加，因为全年的笔数天然较大。先计算每个类别在各窗口中的使用占比，再加权；金额大小不参与。

设 `n_d(c)` 为类别 c 在最近 d 天中的有效使用次数，`N_d` 为同账本、同收支类型在该窗口的总有效次数。默认快捷项的先验占比 `q(c)=1/K`，其他类别为 0，K 为该类型默认快捷项数量。

```text
P_d(c) = [n_d(c) + 5 × q(c)] / [N_d + 5]
Score(c) = 0.60 × P_7(c) + 0.30 × P_30(c) + 0.10 × P_365(c)
```

5 次先验用于平滑冷启动，不是真实使用记录。没有使用记录时保持默认顺序。三个窗口重叠是有意的：近期使用同时获得短期和长期支持。

为减少位置跳动，沿上次排列做稳定插入，仅当候选得分高出相邻项超过 0.02 时才前移；同分保留原位置。第一次使用的新类别追加到候选后遵循同样规则。完整分类列表保持固定分组和顺序，频率仅影响记账页快捷项。

当前草稿期间冻结快捷项顺序：点选、改金额、改日期、从完整列表返回都不重排。成功保存后进入下一笔，或从首页重新进入记账时，再刷新排序。切换收入／支出时加载各自排序。后续可增加手动固定常用项，但当前预览没有置顶功能。

## 当前演示与正式实现边界

预览可演示全部分类、添加自定义小类、选择后保存、加入常用候选和再次记账时重排。使用记录仅保存在当前预览内存中，刷新后恢复默认；不会把输入内容或使用明细保存到宿主状态。

正式应用应将分类、使用贡献和快捷项偏好分别持久化，正确处理修改、删除、同步去重和时钟差异；这些能力尚未实现。具体权重需结合真实使用调整，当前 60／30／10、先验 5 与阈值 0.02 都不是已验证的最优参数。
