# 2026-11-22 紧凑布局与统计审查

依据用户对账户信息密度和图表统计的反馈，先改进网页，再在隔离 API 36 模拟器回看实际 WebView。演示账本、账户、流水均为虚构，工资示例为 6000 元；没有访问用户当前标签中的账目、密钥或未保存输入。

## 发现与处理

| 页面或流程 | 本轮改进 |
| --- | --- |
| 账户总览 | 资产卡收紧为约 148px，总资产和总负债同行；金额隐藏同时覆盖分组汇总。余额说明改为按需打开 |
| 账户分类 | 标题、数量、汇总与展开按钮合成一行。超过四个账户时默认折叠，少量账户展开；记住设备本地的展开偏好。信用卡待还与卡内余款分列，长名称和金额可换行 |
| 首页与录入 | 月历单元从 58px 收至 50px，保留轻立体、折断与日期水印；收紧分类网格和页头，减少进入备注前的滚动 |
| 我的、事件、账本管理 | 统一页标题、分组间距、列表内边距和卡片留白，保留清晰分组与可操作的触控区域 |
| 统计入口 | 月/年/全部/自选日期、上一/下一周期、账户/分类筛选；筛选收起后仍显示生效条件 |
| 统计图表 | 净支出/收入/结余三个指标，趋势/大类/小类/账户四个维度。趋势可点选或拖动读取，环形分布附笔数、金额和占比，排名可展开 |
| 退款与负数 | 使用正负条形图，不把退款净负值放进环形图。转账和借贷本金不计收支，利息使用既有分类，退款按到账时间抵减 |
| 明细查看 | 点击图表或排名进入对应明细，大类先查看小类；每批 50 笔但日小计取完整结果。返回保留统计期间、筛选与选择，切月清除首页旧选日 |
| 保存反馈与安全区 | 保存提示固定在导航上方，滚动后也可见，普通保存约 5.5 秒收起；重要同步/恢复说明仍可手动关闭。使用原生安全区变量或 Web env 回退，不叠加两份边距 |

## 数据边界

本轮只增加统计聚合和界面偏好，不改写任何历史交易，不改变本地加密格式、解锁密码、恢复密钥、登录保持、私有存储或同步协议。统计仅反映当前账本已保存的记录；无记录不代表没有消费，区间日均按完整所选自然天数计算。

运行截图和测试数据库仅保存在忽略目录 `artifacts/ui-review-nov22/`。源码保留可重现的虚构夹具与测试，不收录用户原图或真实财务资料。
