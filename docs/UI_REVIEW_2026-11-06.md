# 2026-11-06 页面体验审查

使用独立浏览器上下文和隔离 Android 模拟器，以虚构账本审查实际构建。用户原有浏览器、账目、密钥和未完成输入不作测试数据。此轮按“网页首页 → 提交推送 → Android 逐页 → 提交推送”执行，不创建公开 Release。

## 第一轮：网页首页

| 实际问题 | 本轮决定与实现 |
| --- | --- |
| 首次使用被整张空日历挤满，不知道先做什么 | 无资金账户时，顶部明确引导添加常用账户；无流水时默认收起日历，仍可展开 |
| 选中日期后明细在屏幕下方，反馈与去向不清晰 | 日历就近显示所选日期、笔数及当日金额，可跳转明细或取消选日；月度概览保持整月口径 |
| 收起筛选后看不出仍有条件生效 | 始终显示可逐项移除的条件标签、匹配笔数及清除动作，明确概览不受明细筛选影响 |
| 没记账、选日无记录、搜索无结果使用同一套提示 | 分别说明原因，提供添加账户、记一笔、清除筛选或查看全部时间等对应动作 |
| 长账本一次绘制全部记录，月份清空可能破坏页面 | 每批 50 笔并可继续加载，日小计与概览仍取完整结果；拒绝无效月份，长筛选文字自动换行 |

保留已确认的墨蓝/暖橙配色、五项导航、轻立体柱体和日期水印。日常刻度的解释按需展开，明确“未记账”不等于“没有花钱”。本轮不改变账户、流水、加密或同步规则。

验证入口：`tests/e2e/home-usability.spec.ts` 与既有 `app.spec.ts`。新增流程覆盖首次入口、选日与分批小计、月份清空、筛选隐藏/清除、长文字及加密记录未改写。浏览器尺寸与 WebKit 不能代替物理设备验收。

第一轮结果：Web 构建及类型检查通过，Edge 桌面、Android 布局与 WebKit iPad 共 21 条流程通过；已查看深浅色、320/393 像素及桌面实际运行截图，无横向溢出。

运行对照图保留于忽略目录 `artifacts/ui-review-nov06/`，不将原始截图或运行账本提交至源码历史。

## 第二轮：Android 逐页审查与处理

在独立 API 36 模拟器中安装单独包名的审查包，使用应用实际 WebView 和系统截图；已有正式包并存，不卸载或清空它。不是拿浏览器手机尺寸冒充 Android 运行。

| 页面或流程 | 观察到的问题与本轮决定 |
| --- | --- |
| 首页与统计的月份 | 系统为英文时，中文应用会显示英文月份；统一可见年月，保留系统选择器。内核不支持月份控件时仍保留可编辑文本，阻止空值破坏页面 |
| 账户列表与账户明细 | 隐藏金额后流水和备注仍可能泄露金额；现在一起隐藏流水金额、日小计、利息和备注，并说明主动打开详情可查看。长名称可换行，保留账户和账本范围说明 |
| 添加/编辑账户 | 起始时间对历史补账的影响不明显；增加按需展开的生活化说明，提示设置在最早补账之前并核对当时余额，保留所有账户类型及方向规则 |
| 记一笔 | 分类网格较高，集中补账要反复滑动找备注；增加直达备注按钮，滚动并聚焦输入。明确识别继续自动填写，手动修正受保护 |
| 分类与账户选择 | 分类已有名称、高亮和图标反馈，继续保留；账户选择补齐当前项高亮及选中语义，避免无法确认点了哪一个 |
| 发生时间 | 原有系统返回行为正确，继续保持只关闭最上层弹窗，不丢弃记账草稿；日期、分类与键盘不改写业务规则 |
| 账目详情与回收站 | 删除结果仍写“删除标记”，误导为只能靠备份找回；改为移入回收站及找回方式。空回收站给出明确提示，恢复前置关系用短句说明 |
| 事件 | 两个空时间分组占用首屏；只显示有事项的分组，完全无事项时用一个空状态引导创建周期账 |
| 周期账与规则表单 | 检查了规则列表、表单、暂停状态和历史入口；继续保留既有行为，不扩大自动生成或自动付款范围 |
| 统计与筛选 | 收起后看不见筛选，无清除动作；补齐范围摘要、清除及日期错误提示。范围变化取消旧钻取；计算解释折叠，零值通道不重复占行 |
| 我的 | 打开状态没有呼应当前账本；补充正在使用的账本名称和管理入口，保持本地解锁、登录与同步分别表达 |
| 账本管理与跨设备同步 | GitHub 说明挤占首屏，本地账本在下方难找；优先展示本地账本，随后提供同步连接。真实授权范围、首次上传确认、按账本取回和冲突核对保持 |
| 解锁、修改密码、恢复密钥及备份恢复 | 保留前轮已经统一的命名、密码验证及恢复前确认，不降低数据保护；检查错误、取消、离线重开和已有账本保持 |
| 短信导入与支持面板 | 保留主动读取范围说明及可选入口；只查看，不申请真实短信权限、读取用户短信或执行付款 |

复核依据为实际运行前后截图及可执行断言。普通页面的小调整同步作用于 Web 与 Android；没有修改资金计算、数据库格式、密码封装或同步协议。公开下载维持原版本，本轮新签名包仅作为本地 `0.1.4-test.2` 验证产物，versionCode 14，包名及长期签名保持。
