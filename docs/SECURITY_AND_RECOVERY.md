# 加密、授权与恢复边界

实施决定：2026-10-21。这里描述已实现格式及操作约束，真实设备和生产授权验收结果另见 IMPLEMENTATION_STATUS.md。

## 本地空间

Web 使用 Dexie/IndexedDB；Android 使用独立 SQLite 原生适配。两者只落盘完整加密空间、密钥封装头、递增存储版本与上一版密文。账本名称、账户、金额、备注、搜索索引不在落盘明文中。解锁后在内存构建查询和余额投影，适用于个人规模账本。

随机 256 位主密钥用于 AES-256-GCM；每次使用独立随机 96 位 nonce，并认证格式版本及用途。解锁口令以 PBKDF2-SHA-256、随机 128 位 salt、600,000 次迭代派生封装密钥。独立的 64 位十六进制恢复密钥表示主密钥。口令和恢复密钥不一起明文保存在数据库。密钥仅在解锁后的内存中，锁定会清除可控原始字节；JavaScript 垃圾回收不能保证所有历史内存副本立即归零。

这能保护复制到其他位置的数据库文件，不能保护已解锁设备、浏览器扩展、恶意脚本、系统管理员或被控制的系统。本机首次创建仍须输入至少 10 字符口令；恢复密钥必须独立保存。浏览器清理站点数据仍可删除密文，不把加密当作备份。

写入先校验完整业务，再加密，最后进行短事务版本比较。失败保留原版与草稿；多个窗口不允许旧版本静默覆盖。每次保留上一版密文，数据库结构升级不采用删库重建。

## 忘记本机解锁口令

0.1.4 测试版在 Web 与 Android 的解锁页提供“忘记口令？”。输入当前本地空间的恢复密钥，设置并再次确认新口令后，可在原地解锁全部已有账本与账目；不依赖备份文件、GitHub 或联网。没有初始化过本地空间时不显示此入口，也不创建空账覆盖数据。

验证会先读取并解密当前密文、检查格式与业务约束；只有正确恢复密钥且新口令满足要求时，才通过 CAS 原子提交新的主密钥封装。主密钥、业务密文、设备身份、实体版本、绑定与设备同步密钥均保持，已加密的 GitHub 凭证仍可恢复。与从备份恢复的“独立设备身份”流程不同，本操作不更换设备身份，也不替换业务数据。

重设时将当前业务快照与新封装一并作为回退检查点，避免旧口令通过“恢复上一版本”再打开当前数据。Web IndexedDB 与 Android SQLite 使用相同事务语义；未知版本、错误或不完整密钥、短口令、存储失败及并发版本变化均拒绝写入。用户提交前可返回解锁并清空敏感输入；提交中的按钮暂不可重复操作。提交完成后页面关闭或再次锁定，不得因迟到回调重新解锁，下次使用新口令。

恢复密钥保持不变，原先导出的备份仍使用当时的口令封装；更改本机口令不撤销那些备份及外部已有副本。密钥应独立保管；没有可用口令、恢复密钥或已解锁副本时无法恢复解密能力。

## 备份与恢复

“我的 → 导出完整加密备份”生成 `.besledger` 文件，包含格式版本、密钥封装和加密数据。保留稳定实体身份、账户期初、退款关联、周期期次、版本向量和删除标记，不包含 GitHub token。

恢复前校验文件大小、格式版本、GCM 完整性、日期/整数金额、引用及业务约束，再显示内容数量。用户确认后替换当前空间并保留上一版本。恢复可使用原口令或恢复密钥，设定新口令，重新生成设备身份，保留实体因果版本。未知未来 schema 拒绝恢复；v1 到 v2 的迁移保留身份与数据。

恢复旧备份不等于撤销云端删除。已同步的删除标记不会被旧快照自动复活。使用“我的 → 回收站”显式恢复，形成继承墓碑的新版本，再同步。先恢复账本、原支出，再恢复相关退款；不自动恢复之前已主动删除的其他流水。

## 同步格式与数据范围

数据仓库必须属于已登录用户且私有，并在每次访问前读回核对。云端文件为 `besledger/v1/<ledgerId>.json`，只暴露随机账本 ID、文件大小、Git 提交时间和密文；账本/账户名称及业务信息均加密。每本账以一个原子文件版本发布，Contents API 的 SHA 比较防止写入覆盖。应用内修改先落盘，主动同步时合并批次并写快照，不把每次键盘编辑上传。

当前采用完整账本快照，尚未实现不可变增量块/历史压缩；Git 历史会增长。单本密文读取上限 25 MB，完整本机备份校验上限 50 MB；达到上限会明确失败，不截断数据。历史密文保留在 Git 中，删除远端当前版本不构成历史擦除。

每个实体使用设备版本向量。独立记录可合并，同笔修改、删除与编辑并发保留双方。合并后再次校验退款等跨记录约束；不满足约束时阻止发布。上传成功但响应丢失，重试根据语义版本识别已完成结果。周期期次使用稳定 ID，墓碑阻止重新补生成。

只上传当前账本及被其引用的共用账户定义，不上传其他仅本地账本的流水或由它们推导的余额。账户余额始终标注“本机已知范围”，不把未下载账本、其他设备本地账当作零。账户期初属于用户明确选择同步的账户定义；首次同步确认时应核对它属于该共用资金账户。

## GitHub 授权与密钥隔离

2026-10-22 改用 GitHub App 的 Device Flow：Web 和 Android 使用同一公开 App ID/client ID/slug，用户安装后在 GitHub 官方页面输入一次性授权码。默认安装范围按用户最新明确选择为 All repositories，以实现首次自动建库。Web 通过固定授权中转端点处理跨域；服务不接收账目或恢复密钥，不落盘或记录 token，但会短暂处理令牌，因此不能宣称维护者在技术上绝不可能接触令牌。

Android versionCode 8 起使用 CapacitorHttp 原生网络直接请求 GitHub 的设备码、换取令牌和续期端点，不经过 Web 中转。固定 HTTPS GitHub 地址、禁用重定向、设置连接/读取超时；不携带 client secret 或 App 私钥。已将 Capacitor loggingBehavior 设为 none，包括调试验收包，避免原生桥接将令牌参数写入日志。原生直连不改变已解锁设备、恶意代码和系统管理员的风险边界。

仅接受 Contents write、Repository creation write、Metadata read 三项能力，不申请 Administration、Workflows、Actions、组织或账号管理权限。All repositories 使令牌具有账号全部及未来仓库内容的读写能力；这是扩大后的真实权限，不属于平台单仓库隔离。开源代码可审查当前行为，但不能保证部署、后续更新或被盗令牌仍遵守代码约束。未授予 Administration 限制整仓管理能力，Contents 写入仍允许修改和删除文件。

当前代码在全部仓库模式下只查询固定候选名和本机已有绑定，不调用全部私有仓库列表。使用专用标记（绑定仓库数字 ID 与 owner ID）或旧加密目录判断账本存储，不靠名称前缀。创建时显式 private，读回归属、仓库 ID、私有性后才初始化标记；读写流水前继续校验。同名未知用途或公开仓库不覆盖，改用稳定备用名。已有绑定不可见时停止，不切换成新空库。selected 模式保留平台范围检查，但不作为默认首次流程。

2026-10-22 按用户要求改为安全保持登录。访问令牌、refresh token、有效期与 GitHub 数字用户 ID 单独加密保存：Web 使用独立 IndexedDB 数据库，Android 使用 SQLite 独立 credentials 表；不进入账本快照、上一版本、导出备份或云端仓库。凭证 AES-256-GCM 密钥通过 HKDF-SHA-256 从随机主密钥派生，使用独立 salt/info 用途标识，与财务数据的 AES 密钥隔离，且不可导出。持久化材料受原有口令封装保护，没有将明文密钥和令牌一起存盘；此方案不宣称使用 Android 硬件 Keystore。

锁定账本只清除内存中的凭证访问能力，保留本机密文；再次本地解锁、页面刷新或进程重启后恢复登录，不要求再次 GitHub 授权。离线时恢复已保存身份；首次联网操作先验证真实 GitHub 数字用户 ID，再访问仓库。账本仍须正常解锁，保持 GitHub 登录不等于绕过本地口令。

Device Flow 只请求 offline_access；支持 GitHub App 短期访问令牌与 refresh token 自动轮换，也兼容同一 GitHub App 的无有效期令牌。临近到期或收到 401 时尝试续期；只有已确认的令牌/refresh token 失效、已过期且无法续期或身份不匹配才清除该登录。断网、超时、403、429 和服务 5xx 不视为退出。Web Locks 串行化同源窗口的轮换；凭证版本比较与退出墓碑防止迟到的刷新结果复活旧登录，同源窗口通过无凭证内容的广播刷新状态。锁定期间已开始的轮换可以只更新密文，不恢复已锁定 UI。

主动退出会删除本机可用凭证并保留版本墓碑，不能从账本备份恢复登录。退出当前设备不撤销 GitHub 服务端对应用的授权，也不撤销其他设备的独立登录；界面提供官方撤销入口。已经发送的网络请求可能已被远端处理，退出后迟到的响应不能重新登录或改写当前 UI。浏览器站点数据清理、卸载、损坏或以另一空间密钥恢复后，可能需要重新授权；不承诺凭证密文的文件系统取证擦除。已解锁设备、恶意脚本及系统管理员仍属于前述保护边界。

2026-10-23 Web/PWA 改为统一使用 https://besledger-github-auth.pages.dev，原 GitHub App 身份不变，同网址更新保留原加密登录。GitHub Pages 与 Cloudflare 备用 Web 是不同来源，浏览器不会共享它们的 IndexedDB；换网址等同新增客户端，须通过备份恢复或同步下载迁移账本并首次登录。PWA 缓存更新不删除账本，清空站点数据则会删除，不应用后者解决更新问题。

0.1.1 起，首次上传自动使用当前空间恢复密钥，成功后记住此账本的同步密钥。另一设备首次下载输入原设备恢复密钥，完成远端解密和完整性验证后才保存；以后返回账本页、刷新、锁定解锁或重启，留空即可自动取用。新设备可有独立本地口令；输入错误密钥不会覆盖已有副本。升级前已下载的外部账本可能需要最后输入一次原设备密钥。

设备同步密钥使用本地主密钥经独立 HKDF-SHA-256 用途派生的 AES-256-GCM 密钥加密，与财务数据及 GitHub 凭证用途隔离。索引是账本 ID、GitHub 数字用户 ID、仓库所有者及仓库名的摘要，并绑定到认证附加数据；不同账号、仓库和账本不会串用。密文存入本机归档可选字段 deviceSyncKeys，Web 使用原 IndexedDB，Android 使用原 SQLite，不增加权限或明文配置，不改变旧账本和云端数据格式。实现使用现有 [Web Crypto](https://www.w3.org/TR/webcrypto/) API。

只有成功解密或首次上传后才与账目一同执行版本比较落盘；验证失败保留旧密钥。锁定会清除当前访问能力，迟到的同步结果不能解锁或写回另一空间。忘记或更换后的旧请求不能把旧密钥重新保存。浏览器运行时不能保证所有历史内存副本立即抹除，已经发送的请求仍可能完成；已解锁设备和恶意脚本的风险边界保持不变。

这些新增设备密钥密文不进入导出备份或云端账本，授权中转也不会收到恢复密钥。恢复备份或上一版本不会恢复已忘记的设备副本；本机归档的上一版本可能仍保留旧密文，不宣称文件系统取证擦除。当前空间自己的主密钥仍按原有恢复设计受口令封装。请继续独立保管原始同步恢复密钥，换设备或恢复外部账本时仍需要它。

在账本卡片点击“同步密钥”→“忘记此设备密钥”，只移除该绑定的本机副本，账目和云端数据不删除。更换保存的密钥时，在原设备密钥输入框填写后再次同步，验证成功才替换；该操作不轮换云端账本的加密密钥。退出 GitHub 只退出账号，已保存的账本同步密钥仍受本地口令保护。

GitHub App 用户令牌也具有读取公开资源的隐式能力。当前默认 All repositories 不提供专用仓库的平台隔离；只有用户主动选择 Only select repositories 才按所选范围限制私有仓库访问。客户端不枚举或读取无关公开仓库。

官方依据：[App 权限边界](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/choosing-permissions-for-a-github-app)、[GitHub App Device Flow](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/generating-a-user-access-token-for-a-github-app)、[令牌续期](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/refreshing-user-access-tokens)、[创建用户仓库](https://docs.github.com/en/rest/repos/repos#create-a-repository-for-the-authenticated-user)。

## Android 签名与工具

本机专用签名保存在 `private/signing/`，Windows ACL 仅允许当前用户与 SYSTEM；JKS 口令使用当前 Windows 用户 DPAPI 加密存入 `credential.clixml`。临时口令文件在 `finally` 中删除。签名由 RSA-3072、SHA256withRSA 生成，别名 `besledger-release`，有效期 10,000 天。公开证书可以发布，私钥、口令及 DPAPI 文件禁止提交。

后续升级必须复用同一签名，不覆盖现有密钥。请将 JKS 和实际口令分别备份到个人安全介质/密码管理器；仅复制 DPAPI 文件到另一台电脑通常无法解密。实际口令的受控备份由维护者在本机完成，不粘贴到聊天中。

使用 PowerShell 7 运行项目构建脚本，独立 JDK 21 和 SDK 路径作为参数传入。环境变量只在当前进程临时设置并恢复；不改变系统 Java、SDK 或其他项目。Android 禁止系统自动备份，使用应用内显式加密备份。

## GitHub App 迁移边界

Repository creation 用于自动新建私有数据仓库。GitHub 自动授予新建仓库访问权；All repositories 范围已经覆盖它。旧 OAuth repo 不再使用，用户已确认撤销旧授权；新版解锁时将登录格式 v1 的旧 OAuth 凭证清除为版本墓碑，不发送旧令牌，账本数据保持不变。注册、默认范围和保留的 selected 选项见 GITHUB_APP_SETUP.md。
