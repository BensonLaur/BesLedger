# 已确认 UI 的设计源码快照

[besledger-ui.html](besledger-ui.html) 保存 2026-10-21 已确认的页面原型，供正式 Vue 工程实现时比对。当前是 HTML 片段，包含 16 个页面、手机/iPad/电脑布局和虚构状态，不能当作正式应用交付。

初版沿用墨蓝与暖灰白、暖橙记账入口；轻立体日历、日期水印、日常刻度折断、首页快捷浮层、预算水印及记账流程详见 [产品设计](../PRODUCT_DESIGN.md) 与 [首页设计](../HOME_DESIGN.md)。最新的新建时间规则已经写入文档，快照尚未实现该规则，实施时以文档为准。

演示数据均为虚构。快照不包含用户原始截图、短信或导出文件。工资与奖金各月示例合计 6,400 元；首页汇总随示例记录计算。其他账户/周期页面仍有独立虚构数据，不代表它们已经共享完整财务引擎。

原预览宿主提供 Lucide 图标、Tweak 调节面板及可选的 window.openai 状态接口。直接以普通文件打开可能缺少图标或预览控制；这是设计源稿，不是独立构建产物。正式应用应安装受许可的图标依赖、去除宿主耦合、用实际路由与持久化替代演示状态，不能依赖宿主注入。

快照使用 light-dark() 等较新 CSS，正式实现需要按 TECH_STACK.md 的兼容目标改写主题变量。不得根据快照在桌面上的效果直接宣称旧 WebView 或 Safari 兼容。

退款详情、账户余额、周期规则、GitHub 连接及同步中有演示分支；必须迁移到真实业务。示例时钟固定于 2026-10-21，正式应用使用可测试的真实时钟。原型的部分金额仍使用浮点演示，正式领域层一律使用整数分。
