# 记账页固定录入布局

## 0.1.4 发布

本文描述的固定记账区、动态备注、滑动选时、账户选择与精简核对均已进入 0.1.4，Android versionCode 20。375 项核心测试和 177 条主要浏览器流程已覆盖通过，模拟授权/同步 12 条完成验证；正式签名包覆盖升级保留旧虚构账目。产物哈希、补测原因与真实设备边界见 [统一发布验收](DELIVERY_VERIFICATION.md#2026-11-23-014-统一发布)，下载见 [v0.1.4](https://github.com/BensonLaur/BesLedger/releases/tag/v0.1.4)。下列 test.3 至 test.7 为各阶段的历史验证记录。

更新：2026-11-22。网页与 Android 共用此布局，不改变金额、分类、账户、退款或本地加密规则。

## 页面分区

| 区域 | 内容与操作 |
| --- | --- |
| 上部固定 | 返回、记账类型、已选分类及金额；选择分类或滚动时仍可核对当前输入 |
| 中间滚动 | 常用分类；“全部”在同一区域展开搜索、分组及自定义分类。转账方向、借贷选项、原支出和利息等也在这里设置 |
| 底部固定 | 自动识别与帮助、紧凑备注、发生时间和资金账户、数字键盘及保存。两端资金流向可从摘要跳转到中间设置 |

普通手机竖屏只滚动中间区域；窄屏减少可见分类行数，不裁掉数字键盘。较矮的横屏采用左右布局。今天的时间显示“今天 HH:mm”，历史日期保留完整年月日；长账户名保留选择入口。

## 备注与键盘

- 备注使用紧凑字号和行距，随内容由一行自动增高，最多约五行；超过上限后只在文本框内部滚动。删除文字时自动缩回，结束编辑后回到开头，完整内容保留。iOS 输入字号保留 16px，避免聚焦时系统自动放大页面。
- 时间与账户改成约 32px 高的扁平按钮；文字键盘打开时仍在备注下面显示，可以直接点击。实际软件键盘只替换应用数字键盘，收起后保留草稿。硬件键盘下可继续使用数字键盘，不只因输入框聚焦就误判。
- 通过可见视口的高度、偏移和焦点状态适配 Web、主屏幕应用与 Android WebView；转动屏幕重新计算，关闭编辑器移除监听。状态栏和手势区沿用现有安全区规则。
- 自动识别仍停顿约 350 毫秒后处理最新备注，组词期间不识别；明确金额和分类直接填入，手改值受保护。开关仍为本机界面偏好，不同步到云端。

## 日期与时间滚轮

点击时间后直接打开一层底部面板，默认“时间”页是邻近日、小时和分钟三个滚轮；“日期”页是年、月、日，不再先打开表单再调用系统选择器。可触摸滑动、鼠标滚动、点击选项或使用方向键，停止时吸附中央；时分可循环滚动，年月变化自动约束短月和闰日。

两页使用同一份临时选择，切换时保留日期和时分；点击“确定”才写回当前草稿，取消和系统返回均保留原时间。手调时分按分钟记账，秒归零；仅改日期保留已有秒数。“现在”可返回当前时间。邻近日初始覆盖前后约半年，更久的旧账在日期页选择。年份到达范围边缘自动扩展，不以固定世纪限制旧账。

滚轮行高随横屏调整；浏览器派发滚动和尺寸通知顺序不同，因此变更行高时按选中值重新定位，不能根据旧像素位置误改时间。所有选择仍受原有账户起算时间与保存前核对规则约束。

## 资金账户选择

选择器按当前用途显示付款、收款、退款入账、转出/转入或往来方标题；沿用借贷两端的实际账户筛选规则，不放宽可选范围。每行展示账户名、银行或类型、尾号、当前余额和选中勾；信用卡待还与卡内余款、应收应付方向沿用账户页解释。余额由已保存的全部账本资金变动计算，不是该条短信余额，也不是记账日期当时余额。

少于 6 个可选账户时只展示紧凑列表，面板按内容决定高度；达到 6 个后显示名称/银行/尾号搜索，默认先放最多 3 个最近使用账户，其余按类型分组，不重复展示同一账户。最近使用只从已保存流水读取。列表滚动、底部添加入口保持可见；没有账户或没有搜索结果时显示对应提示。

账户页与选择器共用金额隐藏开关，切页和重启后保持，设备只保存布尔偏好，不把账户身份或金额存入明文偏好。隐藏时可见金额与辅助说明都以圆点替换。选择即返回草稿，关闭和搜索不写入账本；从面板添加账户或取消后均保留原有金额与备注。搜索键盘打开时使用可见视口约束面板高度。

## 核对与保存

自动识别结果在底部以短句提示，需要核对时点开“备注识别结果”；手动点击识别直接打开该弹框。候选、来源、时间/年份与账户提示保持原有规则，不通过展开大块内容挤走键盘。关闭弹框返回草稿，未解决的歧义仍在保存前提醒。

核对面板顶部突出交易类型和将采用的金额，随后列出“还有几项待核对”和分类、时间、账户三个字段。分类缺失时可在面板内搜索选择，时间复用滑动选择器，账户复用按用途筛选的选择器；年份可就地确认。金额有多个候选时优先显示候选，必要时直接填写。自动模式显示实际保留的手填值，不把被保护字段的识别候选误显示成即将采用的值。

来源、原文时间、用途推荐和备注余额默认收进“识别详情”，余额仍仅供核对并遵循账户金额隐藏开关。其他币种、未完成交易、转账借还及退款等会影响交易含义的提示始终显示。缺金额、分类或账户时主按钮明确指向补齐动作；采用时确认已展示的年份、单位和时间。手动按钮为“采用并返回”，自动按钮为“完成核对”，次要操作统一为“保留我的填写”。

面板中的修改先作为临时核对选择，点主按钮后才应用到草稿；关闭、系统返回或保留填写不撤销已经正常自动填入的明确字段，也不把未采用的候选写回草稿。自动识别与手动保护、退款原支出关联、起算时间及重复记录核对仍沿用原规则。

起算时间与疑似重复记录放在“保存前核对”弹框中，保留历史记录确认、分别调整两端账户起算时间、查看原记录和取消操作。确认调整后重新计算提示，草稿保留。编辑器返回时，“全部分类”先返回常用分类，已有输入仍按原流程询问是否放弃。
