# 第一版完整交付范围

更新：2026-10-21。用户已确认当前页面设计与预算方案，准备从新会话持续实施到 Web 与 Android 可交付。本文件将完整目标与阶段增量区分，优先于较早文档中“一键登录以后再做”“原生入口以后再评估”等排期描述。

当前只有设计文档、虚构样例和 UI 源码快照，以下清单均为待实施要求，不代表功能已经完成。

## 交付物

1. 可运行的 Vue/TypeScript 正式应用及完整源码、锁定依赖、可复现运行和构建命令。
2. 可部署的 Web/PWA 生产产物、离线与更新流程、GitHub Pages 子路径配置；实际部署后记录可访问 URL 和验证结果。
3. Capacitor Android 工程及可安装的签名 APK，记录版本、文件大小、SHA-256、最低系统和签名性质。至少完成构建、签名校验和可用环境中的安装运行；正式发布使用专用长期签名，调试签名必须标明。签名密钥与口令不入库。
4. 真实 GitHub 登录与注销、独立私有数据仓库创建/选择、账本加密上传下载和双端编辑同步。不能以开发者 gh 凭证、模拟登录、PAT 输入框或浏览器单机状态替代。
5. 自动化测试、构建记录、兼容范围、已验证设备、部署和恢复文档。明确人工真机验证与自动化/模拟器测试的区别。

iPad 原生构建暂缓，但共享界面应兼顾 iPad Safari/PWA。原型是设计参考，不能直接打包后称为正式产品。

## GitHub 与隐私约束

- 源码公开仓库与账本私有仓库分离。创建远端时显式设置 private 并读回校验，发现公开仓库时不得上传账目。
- 账目在客户端加密后上传，认证凭证与账本密钥分离。云端目录、名称和账户元数据的明文范围要有明确最小化设计；私有仓库不替代加密。
- 登录连接需要验证完整授权流程、回调/设备码、拒绝、失效、退出和重连。选择 GitHub App/OAuth App 前核对 Web、Android、创建私有仓库及部署方式的可行性；需授权服务时提供真实配置、部署和可验证的回调。
- GitHub App 的安装授权范围、OAuth scope 与仓库创建能力不能凭想象组合。PAT 保留为高级备用能力，但不满足“一键 GitHub 登录”的验收。
- 不得将开发机 gh token、OAuth client secret、签名材料、解密密钥打进 Web、APK、公开仓库、日志或测试报告。授权服务不接收账目明文或解密密钥。
- 不因某本账启用同步而上传另外一本仅本地账的数据；未下载流水不按零处理，账户余额缺少数据时明确说明范围。
- 真实 XLSX、短信、截图、工资、卡号、交易金额/商家/时间组合不用于公开测试。演示数据均为虚构。用户提供的私人资料不自动导入或上传，即使目标是私有仓库也需要明确的数据使用指示。

## 可以由实施者决定的细节

用户允许在实现中合理决策并后续调整：依赖补丁版本、模块划分、表结构与索引、SQLite 驱动、图表实现、组件拆分、状态与错误文案细节。遵循已确认交互和业务口径，必要时写简短决策记录，不为常规选择反复询问。

在真实持久化前确定本地落盘加密、索引、解锁和恢复方案，准确说明保护范围。同步格式、密钥封装和凭证保存需有威胁与恢复边界；不要为追求“无感”把密钥和密文无保护地放在一起却声称具备独立加密保护。参数与 schema 可版本化迁移，已有数据不能被升级清空。

初始版本采用 TECH_STACK.md 中 Android 10/API 29、compile/target 36、Capacitor 8、JDK 21、Node 24 LTS。版本因兼容证据调整时说明理由并锁定验证过的组合，无需等待用户逐个批准。

## 条件性能力与暂缓范围

- Android 短信读取：在自用 APK 和目标系统验证权限、范围筛选、勾选识别、拒绝/撤回；可行则实现，平台或分发限制时保留完整备注粘贴并记录原因。不能以强制默认短信应用、过度权限或绕过限制实现。
- 暂缓 iPad 原生包、挖财历史自动迁入、跨币种、多人协作、复杂分期/自动计息、周期账追溯批量改写、OCR、全部银行模板及无条件后台准时执行。
- GitHub 登录、私有仓库创建和多端同步不属于可以省略的条件性功能。

## 关键验证路径

1. 空白设备离线创建账本和账户，期初起算；记收支/转账，编辑删除，重启核对余额与明细；备份恢复后金额及关联一致。
2. 固定时钟覆盖选过去日、今天、历史整月、全部时间、跨午夜；短信时间优先级和从分类返回不重置。
3. 完整借还：本金不计收支、利息单独统计，组合修改删除原子完成；覆盖仅付息和利息大于总额。
4. 多次退款、跨账户/跨月退款、净负支出；周期规则旧期次补齐、新期次修改、两设备重试与删除后不再生成。
5. 创建真实私有测试仓库，用虚构账目在两个独立本地存储环境（含 Android 运行环境时优先）验证首次上传、已有远端发现、下载、双向编辑、离线重连、并发冲突、删除与授权失效；模拟 API 测试不能代替真实 API 集成证据。
6. Web/PWA 子路径、首次资源缓存后离线重开、生产刷新和更新迁移；Android 构建、签名、启动、权限拒绝、返回键、前后台和软键盘；兼容性结论只覆盖实际验证范围。
7. 发布前检查 Git 历史、构建输出、源码映射、日志、截图和测试资源，确保只有虚构财务数据且无密钥。

## 完成与阻塞的定义

分阶段报告进展，不能在脚手架、假数据页面或仅能构建 APK 时宣布全部完成。收尾提供交付物位置、Web URL、测试摘要、设备矩阵和已知限制。必需功能缺失必须列为未完成。

若 OAuth 注册、外部账号登录、二次验证、权限授予或真实设备接入只能由用户完成，先完成可独立推进的代码、配置模板、自动化测试与构建，再明确唯一所需动作及原因；不能把外部阻塞包装成成功，也不要求用户提供整个账户的长期密钥到聊天中。
